# Maquetación Web Responsive y Accesibilidad - Diseño de Interfaces de Usuario

Prácticas de la asignatura **Diseño de Interfaces de Usuario / Interacción Persona-Ordenador (UC3M)**.

---

## 📌 Descripción

Desarrollo de interfaces web modernas, accesibles y totalmente responsivas orientadas a la mejor experiencia de usuario (UX/UI).

### Características Principales:
* **Diseño Responsive:** Maquetación fluida adaptada a móviles (600px), tablets (768px) y escritorio usando CSS Flexbox y CSS Grid.
* **Unidades Relativas:** Uso de `rem` y variables CSS para escalabilidad tipográfica y consistencia de diseño.
* **Variantes de Diseño (Tests A/B/C):** Implementación de diferentes versiones de interfaz para evaluar usabilidad.
* **Estándares Web:** Validación de código según los estándares del **W3C** (HTML5 y CSS3).

---

## 🌐 Tecnologías

* HTML5 Semántico
* CSS3 (Flexbox, Grid, Media Queries)
* JavaScript Vanilla
